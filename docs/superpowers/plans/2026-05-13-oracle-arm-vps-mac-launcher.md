# Oracle Free Tier ARM VPS — macOS Launcher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a macOS scaffolding layer around the upstream `oracle-freetier-instance-creation` Python tool so it runs as a `launchd` LaunchAgent on the user's Mac, retrying every 60 s until an ARM A1.Flex (4 OCPU / 24 GB / 200 GB boot / 120 VPU / public IP / Ubuntu 24.04) instance is created in `eu-stockholm-1`.

**Architecture:** Clone upstream into `oracle-freetier-instance-creation/` (never modified). Wrap with: a one-time bootstrap (`setup_mac.sh`), a control script (`vps-ctl.sh`), a launch wrapper (`run_loop.sh`), a one-shot post-success VPU bump (`post_create_vpu_bump.py`), and a LaunchAgent plist template. Successful instance creation triggers an automatic OCI API call to set the boot volume's `vpus_per_gb` to 120.

**Tech Stack:** zsh / bash, Python 3 (system or `brew install python@3.12`), upstream `oci` Python SDK + `python-dotenv` (installed into venv from upstream `requirements.txt`), macOS `launchd` / `launchctl`, `plutil` (built-in macOS plist linter).

**Spec:** [docs/superpowers/specs/2026-05-13-oracle-arm-vps-mac-launcher-design.md](../specs/2026-05-13-oracle-arm-vps-mac-launcher-design.md)

#!/bin/zsh
# LaunchAgent entrypoint. Runs the upstream retry loop, then runs the
# post-creation VPU bump on clean success.

set -u

SCAFFOLD_ROOT="$(cd "$(dirname "$0")" && pwd)"
UPSTREAM_DIR="$SCAFFOLD_ROOT/oracle-freetier-instance-creation"

if [ ! -d "$UPSTREAM_DIR/.venv" ]; then
  echo "[run_loop] venv missing at $UPSTREAM_DIR/.venv — run ./setup_mac.sh first" >&2
  exit 64
fi

cd "$UPSTREAM_DIR"
"$UPSTREAM_DIR/.venv/bin/python" main.py
status=$?

if [ $status -eq 0 ] && [ -f INSTANCE_CREATED ]; then
  echo "[run_loop] instance created — running VPU bump"
  "$UPSTREAM_DIR/.venv/bin/python" "$SCAFFOLD_ROOT/post_create_vpu_bump.py" \
    || echo "[run_loop] VPU bump failed; instance is still created and usable" >&2
fi

exit $status
```

"""Bump the freshly-created instance's boot volume to 120 VPU.

Designed to be invoked by run_loop.sh after upstream main.py exits 0 and
INSTANCE_CREATED is written. Idempotent: writes VPU_BUMPED on success and
short-circuits if that file already exists.
"""
from __future__ import annotations

import re
import sys
from pathlib import Path

UPSTREAM_DIR = Path(__file__).resolve().parent / "oracle-freetier-instance-creation"
INSTANCE_CREATED_FILE = UPSTREAM_DIR / "INSTANCE_CREATED"
VPU_BUMPED_FILE = UPSTREAM_DIR / "VPU_BUMPED"
OCI_CONFIG_FILE = UPSTREAM_DIR / "oci_config"
TARGET_VPU = 120

INSTANCE_OCID_PATTERN = re.compile(r"ocid1\.instance\.oc1\.[A-Za-z0-9_.\-]+")


def extract_instance_ocid(content: str) -> str:
    match = INSTANCE_OCID_PATTERN.search(content)
    if not match:
        raise ValueError("No instance OCID found in INSTANCE_CREATED content")
    return match.group(0)
```

# Control surface for the Oracle Free Tier ARM VPS launcher.

require_setup() {
  if [ ! -d "$UPSTREAM_DIR/.venv" ]; then

  fi

    exit 65

    echo "ssh_public_key.pub missing in $UPSTREAM_DIR" >&2
    exit 65
  fi
}

case "$cmd" in
  test)
    require_setup
    mkdir -p "$LOG_DIR"
    echo "[vps-ctl] running foreground smoke test (~150s) — Ctrl+C to abort early"
    cd "$UPSTREAM_DIR"
    # Run upstream in foreground with a 150s timeout. perl is used because

    status=$?
    cd "$ROOT"

    LOG_FILE="$UPSTREAM_DIR/launch_instance.log"
    if [ ! -f "$LOG_FILE" ]; then

      exit 1

    echo "[vps-ctl] attempts observed in launch_instance.log: $attempts"
    if [ "$attempts" -ge 2 ]; then
      echo "[vps-ctl] PASS: loop fired at least twice"
      exit 0
    else
      echo "[vps-ctl] FAIL: loop did not fire twice; check $LOG_FILE"
      exit 1
    fi

    echo "[vps-ctl] $cmd not yet implemented" >&2

vps-ctl.sh — control surface for the Oracle ARM VPS launcher

Usage: ./vps-ctl.sh <command>

A macOS scaffolding around [mohankumarpaluru/oracle-freetier-instance-creation](https://github.com/mohankumarpaluru/oracle-freetier-instance-creation) that hunts for Oracle Free Tier ARM capacity (`VM.Standard.A1.Flex`, 4 OCPU / 24 GB / 200 GB boot / 120 VPU / public IP / Ubuntu 24.04) in `eu-stockholm-1` and stops when one is provisioned.
